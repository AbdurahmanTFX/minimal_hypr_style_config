# minimal_hypr_style_config

Конфиг Hyprland (Lua-конфиг, Hyprland 0.55+, проверен на 0.57) со своей
оболочкой вместо панели: 6 рабочих столов по 9 профилей, обзоры столов и
профилей, терминальный dashboard и уведомления в едином стиле: чёрный фон,
JetBrainsMono, цвета kanagawa-dragon.

## Возможности

### Рабочие столы и профили

- 6 рабочих столов сеткой 3×2, у каждого 9 профилей (наборов окон).
  Номер воркспейса Hyprland: `стол + (профиль − 1) × 6`, всё считается в
  `MyScripts/config.sh` и `MyScripts/config.h`.
- `Alt+Tab` переключает между текущим профилем и его «TAB-партнёром».
- Свайп тремя пальцами переключает столы через ту же навигацию, что и
  клавиатура, поэтому модель профилей не ломается. Работает только на
  мультитач-тачпадах, см. «Ограничения».
- Окна можно прятать в список текущего профиля и возвращать по одному или
  из панели.
- Show desktop прячет все окна текущего стола и возвращает их в прежнем
  порядке фокуса.

### Обзоры (Cairo и Wayland, без GTK)

- **Обзор столов** (`Ctrl+Alt+E`): все 6 столов с превью, активный подсвечен.
- **Обзор профилей** (`Ctrl+Alt+P`): 9 профилей активного стола с превью,
  отметками `ACT` (активный) и `TAB`. Открывается на том столе, где ты сейчас.
- **Скрытые окна профиля** (`Alt+Super+V`).
- Превью снимаются до перехода на другой стол, без кадров анимации.
  Размер монитора берётся настоящий.
- Скрытые панели не обновляются в фоне и не тратят батарею; открываются
  всегда со свежими данными.

### Dashboard (`Ctrl+Alt+I`)

Терминальная панель на FTXUI в kitty, пять вкладок:

- **SYS:** время, дата, батарея, сеть и Bluetooth (Enter открывает
  окно управления), яркость, текущие стол и профиль, раскладка клавиатуры.
  Строка сети показывает, через что идёт интернет: `󰈀 Кабель` или
  `󰖩 Wi-Fi «сеть»`; если подключено и то и другое, Wi-Fi помечен как запасной.
- **AUDIO:** общая громкость, звук уведомлений и громкость каждого
  приложения, отдельный mute для каждой строки.
- **NOTIF:** история уведомлений, режимы silent и hide, громкость
  звука уведомлений.
- **WIN:** список окон с переходом к окну, фоновые сервисы.
- **NOTES:** файлы заметок и быстрая заметка; всё открывается в nvim.

Скрытый dashboard не обновляется (терминал сообщает о потере фокуса), при
возврате данные обновляются сразу.

### Уведомления (dunst)

- Стиль dashboard, рамка по важности: cyan обычные, красные важные,
  жёлтые предупреждения о батарее.
- Обычные держатся 5 секунд, важные 15. Приложения, которые просят «не
  закрывать никогда» (например, Firefox), тоже закрываются через 5 секунд.
- Свой звук уведомления: громкость и mute настраиваются в dashboard.
  Индикаторы и уведомления с низким приоритетом звучат без сигнала;
  если сигналов несколько подряд, звучит только первый.
- **Silent:** уведомления не показываются и не звучат, но остаются в
  истории.
- **Hide:** вместо уведомления на секунду появляется точка, текст остаётся
  в истории.
- Индикаторы собственных действий (профиль, край стола, тачпад, обои,
  раскладка) работают в любом режиме.
- При смене раскладки появляется короткое `RU` или `US` без звука, в историю
  оно не попадает.
- При 35% заряда приходит предупреждение, а яркость один раз снижается до
  40%; потом её можно вернуть вручную.

### Блокировка

- `Super+L`, автоматически через 10 минут простоя (за минуту приходит
  предупреждение) и перед сном.
- Экран блокировки в стиле dashboard: размытый снимок экрана, время, поле
  пароля и текущая раскладка.
- Если `hyprlock` упадёт, сессию можно разблокировать, запустив его заново
  из tty (`misc.allow_session_lock_restore`).

### Прочее

- Все горячие клавиши панелей работают и в русской раскладке; текстовый
  ввод (имя заметки, пароль Wi-Fi) набирается как есть.
- Polkit-агент (`hyprpolkitagent`), чтобы программы могли спросить пароль.
- Статичные и живые обои (`awww`, `mpvpaper`).

## Горячие клавиши

`Super` — клавиша Windows.

| Клавиши | Действие |
|---|---|
| `Super+T` / `Super+Y` / `Super+F` / `Super+R` | kitty / yazi / Firefox / zathura |
| `Ctrl+Alt+S` | меню приложений (rofi) |
| `Super+L` | заблокировать экран |
| `Alt+Super+X`, `Alt+Super+F4` | закрыть окно |
| `Alt+Super+F` | полный экран |
| `Alt+Super+H/J/K/L` | фокус на соседнее окно |
| `Ctrl+Super+H/J/K/L` | переместить окно в раскладке |
| `Shift+Super+стрелки` | изменить размер окна |
| `Super+ЛКМ` / `Super+ПКМ` | перетащить / изменить размер мышью |
| `Ctrl+Alt+H/J/K/L` | соседний рабочий стол |
| `Super+Shift+H/J/K/L` | перенести окно на соседний стол |
| `Ctrl+Alt+1…9` | профиль 1…9 текущего стола |
| `Super+Shift+1…9` | перенести окно в профиль 1…9 |
| `Alt+Tab` | текущий профиль ↔ TAB-партнёр |
| `Alt+Super+C` / `Alt+Super+S` | спрятать окно / вернуть последнее |
| `Alt+Super+V` | панель скрытых окон профиля |
| `Ctrl+Alt+D` | show desktop |
| `Ctrl+Alt+I` / `Ctrl+Alt+E` / `Ctrl+Alt+P` | dashboard / обзор столов / обзор профилей |
| `Ctrl+Alt+T` | время и заряд уведомлением |
| `Ctrl+Alt+W` / `Ctrl+Alt+N` / `Ctrl+Alt+B` | обои: статичные ↔ живые / следующие / выбрать |
| `Ctrl+Alt+O` | включить или выключить тачпад |
| `Print`, `Super+Print`, `Shift+Print` | скриншот экрана / окна / области |
| `Ctrl+Print` | область с правкой в swappy |
| `Alt+Shift` | сменить раскладку (us ↔ ru) |
| Свайп тремя пальцами влево / вправо | следующий / предыдущий стол (только мультитач-тачпад) |

### Клавиши внутри панелей

**Dashboard:** `1–5` (или `Alt+H`/`Alt+L`) переключают вкладки, `Q` закрывает.

| Вкладка | Клавиши |
|---|---|
| SYS | `J/K` выбор, `H/L` яркость, `Enter` окно Wi-Fi или Bluetooth |
| AUDIO | `J/K` выбор строки, `H/L` громкость, `M` mute выбранной строки |
| NOTIF | `J/K` прокрутка, `H/L` громкость звука, `M` mute, `S` silent, `C` hide, `D` очистить историю |
| WIN | `J/K` выбор, `Enter` перейти к окну, `D` закрыть окно |
| NOTES | `J/K` выбор, `A` новый файл, `D` убрать из списка, `Enter` открыть, `Tab` быстрая заметка |

**Обзор столов:** `hjkl` или стрелки, `1–6` прямой переход, `Enter` перейти,
`q`/`Esc` закрыть.

**Обзор профилей:** `hjkl` или `1–9`, `Enter`/`a` перейти, `t` назначить TAB,
`s` скрытые окна выбранного профиля, `r` обновить, `q`/`Esc` закрыть.

**Скрытые окна:** `j/k`, `Enter`/`a` вернуть окно, `r` обновить, `q`/`Esc`
закрыть.

**Wi-Fi:** `j/k`, `Enter` подключиться, `d` отключиться, `s` пересканировать,
`r` обновить, `q` закрыть.

**Bluetooth:** `j/k`, `Enter` подключиться, `d` отключиться, `s` поиск
устройств, `p` питание адаптера, `r` обновить, `q` закрыть.

## Установка

Зависимости (Arch Linux):

```sh
sudo pacman -S --needed hyprland dunst kitty rofi yazi neovim zathura firefox \
    hyprlock hypridle hyprpolkitagent hyprshot swappy grim jq socat python \
    brightnessctl playerctl libnotify wireplumber pipewire-pulse \
    networkmanager bluez-utils sound-theme-freedesktop ttf-jetbrains-mono-nerd \
    cmake gcc make pkgconf git wayland wayland-protocols wlr-protocols cairo libxkbcommon
# обои: awww и mpvpaper (AUR)
```

Конфиг и сборка:

```sh
mv ~/.config/hypr ~/.config/hypr.old   # если там уже что-то есть
git clone https://github.com/AbdurahmanTFX/minimal_hypr_style_config ~/.config/hypr
make -C ~/.config/hypr/MyScripts install     # FTXUI скачается при первой сборке
mkdir -p ~/.config/dunst
ln -sf ~/.config/hypr/dunst/dunstrc ~/.config/dunst/dunstrc
```

Остальное по желанию:

- Свой звук уведомлений положить в `~/.config/hypr/sounds/notification.mp3`,
  иначе играет системный `message.oga`.
- Цвета dashboard берутся из `~/.config/kitty/kitty.conf`: его подключает
  `kitty-dashboard.conf`. В оригинале это тема kanagawa-dragon с чёрным фоном.
- Обои: статичные в `~/Pictures/wallpapers/dashboard`, живые в
  `~/Videos/wallpapers`. Скриншоты сохраняются в `~/Pictures/Screenshots`,
  заметки dashboard лежат в `~/Documents/Notes/dashboard`.

После изменения исходников C++ снова выполни `make -C ~/.config/hypr/MyScripts install`
и перезапусти панели: они работают в фоне, так что старая версия продолжит
работать, пока процесс не перезапущен.

## Структура

```
hyprland.lua              основной конфиг Hyprland
hypridle.conf             блокировка при простое и перед сном
hyprlock.conf             экран блокировки
dunst/dunstrc             уведомления: стиль, режимы, звук, таймауты
kitty-dashboard.conf      kitty для dashboard
audio-parse.py            список аудиопотоков для вкладки AUDIO
MyScripts/
  config.sh, config.h     общие настройки скриптов и программ
  ws-navigate.sh          переходы между столами
  profile-switch.sh       профили и Alt+Tab
  show-desktop.sh         show desktop
  hidden-apps.sh          скрытые окна профиля
  toggle-*.sh             показ и скрытие панелей
  battery-guard.sh        предупреждение о заряде
  layout-notify.sh        уведомление о смене раскладки
  notif-sound.sh          звук уведомлений
  wallpaper-*.sh          обои
  toggle-touchpad.sh      тачпад
  dashboard.cpp           dashboard (FTXUI)
  bt-popup.cpp            окно Bluetooth (FTXUI)
  wifi-popup.cpp          окно Wi-Fi (FTXUI)
  layout_keys.hpp         клавиши FTXUI-программ в русской раскладке
  net_status.hpp          через что идёт интернет: кабель или Wi-Fi
  overview/               обзоры столов и профилей, панель скрытых окон
  Makefile, CMakeLists.txt
```

Собранные программы, заметки, настройки звука и сам звук в репозиторий
не входят (см. `.gitignore`).

## Ограничения

- Проверено на одном мониторе ноутбука 1366×768. Окна на других мониторах
  в превью не учитываются.
- Свайпы не работают на старых тачпадах PS/2 с semi-MT (например,
  `SynPS/2 Synaptics TouchPad`): libinput отключает на них жесты, и до
  Hyprland они не доходят. Проверить свой тачпад: `B: PROP=` в
  `/proc/bus/input/devices` с битом 3 (semi-MT), например `PROP=9`.
- Окно polkit-агента в работе не проверялось.
